# 计算器工具调用流程

下图对应 `test/test_calculator.py` 中的 `test_with_simple_agent()`，参考示例使用时序图展示调用方向、返回结果及两个处理阶段。

当前测试通过测试函数模拟 Agent 的编排过程，没有创建或调用 `SimpleAgent` 实例。表达式由测试代码指定，模型负责把计算结果组织成自然语言回答。

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户
    participant Test as 测试函数（模拟 Agent 编排）
    participant LLM as HelloAgentsLLM
    participant Registry as ToolRegistry
    participant Calc as 计算器 calculate
    participant API as 模型服务 API

    Note over Test,API: 准备：create_llm() 创建客户端；create_calculator_registry() 注册 my_calculator → calculate
    Note over User,Test: 测试代码预设问题，模拟用户输入
    User->>Test: 请帮我计算 sqrt(16) + 2 * 3

    rect rgb(255, 248, 235)
        Note over Test,Calc: 第一阶段：执行计算器工具
        Test->>Registry: execute_tool("my_calculator", "sqrt(16) + 2 * 3")
        Registry->>Registry: 从 _functions 中取出对应的 func
        Registry->>Calc: calculate("sqrt(16) + 2 * 3")
        Calc->>Calc: ast.parse(expression, mode="eval") 解析表达式
        Calc->>Calc: _eval_node() 递归计算：4.0 + 6
        Calc-->>Registry: 返回字符串 "10.0"
        Registry-->>Test: 返回 calc_result = "10.0"
    end

    rect rgb(237, 246, 255)
        Note over Test,API: 第二阶段：生成自然语言回答
        Test->>Test: 构建 final_messages，包含原问题和计算结果
        Test->>LLM: response = llm.think(final_messages)
        LLM-->>Test: 返回生成器，此时尚未发送请求
        Test->>LLM: for chunk in response：开始迭代
        LLM->>API: chat.completions.create(messages=..., stream=True)
        loop 逐块返回，直到响应结束
            API-->>LLM: 返回响应片段
            LLM-->>Test: yield chunk（文本片段）
            Test->>Test: print(chunk, end="", flush=True)
        end
    end

    Note over Test,User: 终端展示模型回答，下面仅为示例措辞
    Test-->>User: sqrt(16) = 4，2 × 3 = 6，所以结果是 10。
```

## 关键角色

| 角色 | 对应代码 | 核心职责 |
|---|---|---|
| 测试函数 | `test/test_calculator.py` 的 `test_with_simple_agent()` | 指定问题和表达式，调用工具，再把结果交给模型 |
| 工具注册表 | `tools/registry.py` 的 `ToolRegistry` | 按工具名称查找并调用注册的函数 |
| 计算器 | `tools/calculator_tool.py` 的 `calculate()`、`_eval_node()` | 把表达式字符串解析成语法树，再递归求值 |
| LLM 客户端 | `core/llm.py` 的 `create_llm()` 返回的 `HelloAgentsLLM` | 连接模型服务，并通过 `think()` 提供流式文本 |
| 模型服务 API | 客户端配置的 `base_url` 和 `model` | 根据问题与工具结果生成回答 |

## 阅读说明

- 实线箭头表示调用或发送数据，虚线箭头表示返回。
- `my_calculator` 是注册名称，`calculate` 才是实际执行的 Python 函数。
- 工具在本地完成数学计算，不需要请求模型服务；模型在后续阶段生成自然语言回答。
- 使用 OpenAI 兼容接口不代表请求一定发给 OpenAI；实际目标由 `create_llm()` 选择的配置决定。
- `think()` 返回生成器，开始迭代后才执行请求；每个 `chunk` 是一段文本，不保证恰好是一个字或一句话。
- 当前 `think()` 自身也打印文本，测试中的 `print(chunk, ...)` 会再次打印同一片段；图中保留测试代码的调用关系。
