# 流程图视图说明

核对日期：2026-10-17。启动 `python web/serve.py`，访问 <http://127.0.0.1:5173>，在顶部选择“流程图”。这是 [Agent 架构与流程演示](Agent研发地图说明.md) 中的独立视图，与可拖动节点的架构画布分开操作。

## 按需浏览

- 通过下拉框选择场景，按需阅读，不设置额外侧边栏。
- 跨组件调用用时序图；分支、循环和递归入口用流程图。
- 默认 100%，支持适应画布、右键或中键平移、Ctrl + 滚轮缩放。普通滚轮滚动页面，顶部工具区滚出屏幕后，加高的画布可以基本占满屏幕。每个场景分别保留本次会话的缩放和平移位置。
- 点击图中带下划线的节点或消息，在大弹窗查看真实源码与说明；图下方也提供全部相关源码入口。关闭弹窗后继续浏览原图。
- 源码弹窗中的“相关流程图”可以反向进入对应场景。只有有明确关联的函数才显示入口。
- 图定义默认折叠，按需展开查看来源或复制 Mermaid。

计算器编排直接复用 [原有计算器文档](计算器工具调用流程.md) 的图，其他图定义集中于 [核心代码流程](flows/核心代码流程.md)。这些图是对源码的静态讲解，不是运行追踪，不会执行 Python 或访问模型服务。

相关源码入口全部指向项目本地模块。`create_llm()` 返回 `core.llm.LLM`，SimpleAgent 与 ReActAgent 直接继承本地 Agent，使用本地 Config、Message、ToolRegistry。`test_calculator_with_llm()` 手动编排函数工具 `calculate` 和模型，没有实例化 Agent；真实 SimpleAgent 示例注册对象工具 `calculator`，位于 `test/test_simple_agent.py`。ReAct 的 FakeLLM 离线验证在 `test/test_react_agent.py`；默认模板 `DEFAULT_REACT_PROMPT` 可从流程图或构造函数中的链接进入源码弹窗。

搜索与编排流程复用 [搜索工具与测试说明](搜索工具与测试说明.md)、[工具链与异步执行说明](工具链与异步执行说明.md) 中的图，已登记到 `web/flows.json`。

## 维护方式

1. 更新 Python 后，核对节点、讲解与真实执行路径。
2. 修改对应 Markdown 的 Mermaid 图；图定义只维护一份。`flows/核心代码流程.md` 的前七个图块与计算器文档的第一个图块已按序号关联，不随意调整顺序；增删时要同时更新 `web/flows.json`。
3. `web/flows.json` 维护场景标题、文档位置、代码块序号和源码关联。`sources` 使用准确文件路径与限定符号；`match` 用于为可见图形标签添加源码入口，没有匹配的引用仍显示在图下方。
4. 运行 `python web/generate_sources.py`，生成 `sources.json` 和 `diagrams.json`；重启预览也会自动生成。生成器检查重复场景 ID、文档范围及 Mermaid 块是否存在。
5. 检查所有图、源码入口和反向流程入口。不手动修改生成的 JSON。

`web/diagrams.js` 负责视图、缩放、平移及跳转，`web/diagrams.css` 延续中性白灰和蓝灰配色。Mermaid 11.17.2 在 `web/vendor` 本地提供，仅进入流程视图时加载，不使用远程 CDN。相关版本、许可证与更新命令见 `web/vendor/README.md`。

当前代码边界在图和讲解中保留：schema 方法依赖未定义成员；计算器没有 UnaryOp 分支；SimpleAgent 的一般名称分支只查对象表；SearchTool 尚未完成抽象接口。注册表现已支持对象优先执行和 unregister_tool，不再提示旧的接口缺失。展示这些内容不代表通过真实模型或搜索调用测试。

## 常见问题

| 表现 | 检查方式 |
|---|---|
| 修改 Markdown 后页面仍显示旧图 | 重新生成索引，再刷新页面 |
| 本地源码入口缺失 | 核对白名单与文件限定符号；脚本只依赖 Python 标准库，无需安装业务库 |
| 点击标签没有跳转 | 核对 `sources` 的文件、限定符号和 `match`；未匹配项可从图下方入口打开 |
| 围栏新增后场景显示错图 | 检查 `web/flows.json` 的 `block`，该编号从 0 开始 |
