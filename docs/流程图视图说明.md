# 流程图视图（C 方案）

启动 `python web/serve.py`，访问 http://127.0.0.1:5173，在顶部选择“流程图”。地图仍默认简化为 6 个组件，“完全展开”显示当前 23 个节点。

## 按需浏览

- 主页面新增独立流程视图，通过下拉框选择场景，不增加侧边栏。
- 跨组件调用用时序图；分支、循环和递归入口用流程图。
- 默认 100%，支持适应画布、右键或中键平移、滚轮平移、Ctrl + 滚轮缩放。每个场景分别保留本次会话的缩放和平移位置。
- 点击图中带下划线的节点或消息，在大弹窗查看真实源码与说明；图下方也提供全部相关源码入口。关闭弹窗后继续浏览原图。
- 源码弹窗中的“相关流程图”可以反向进入对应场景。只有有明确关联的函数才显示入口。
- 图定义默认折叠，按需展开查看来源或复制 Mermaid。

## 当前八个场景

| 场景 | 图类型 | 重点 |
|---|---|---|
| 模型配置解析 | 流程图 | 服务、模型、地址与凭证来自同组配置 |
| main 流式请求 | 时序图 | 创建生成器与真正开始请求的区别 |
| Agent 普通对话 | 时序图 | 上下文、invoke 与框架历史方法 |
| Agent 工具循环 | 流程图 | 文本标记、调度、回传、迭代上限 |
| Agent 流式对话 | 时序图 | 转发片段，完整消费后保存历史 |
| 计算器编排调用 | 时序图 | 测试手动执行工具，再让模型回答 |
| 计算器递归求值 | 流程图 | AST 节点分派与当前未实现分支 |
| 本地注册与调度 | 流程图 | 函数表和对象表的实际行为 |

计算器编排直接复用 [原有计算器文档](计算器工具调用流程.md) 的图，其他图定义集中于 [核心代码流程](flows/核心代码流程.md)。这些图是对源码的静态讲解，不是运行追踪，不会执行 Python 或访问模型服务。

地图已加入本地工具基类、注册表、计算器、递归求值与两个测试入口。明确区分本地 `tools/registry.py` 和框架 `hello_agents/tools/registry.py`；`test_with_simple_agent()` 虽然名称包含 Agent，实际没有实例化 Agent，真实 Agent 测试则在 `test/test_simple_agent.py`。

## 维护方式

1. 更新 Python 后，核对节点、讲解与真实执行路径。
2. 修改对应 Markdown 的 Mermaid 图；图定义只维护一份。
3. `web/flows.json` 维护场景标题、文档位置、代码块序号和源码关联。`sources` 使用准确文件路径与限定符号；`match` 用于为可见图形标签添加源码入口，没有匹配的引用仍显示在图下方。
4. 运行 `python web/generate_sources.py`，生成 `sources.json` 和 `diagrams.json`；重启预览也会自动生成。生成器检查重复场景 ID、文档范围及 Mermaid 块是否存在。
5. 检查所有图、源码入口和反向流程入口。不手动修改生成的 JSON。

`web/diagrams.js` 负责视图、缩放、平移及跳转，`web/diagrams.css` 延续中性白灰和蓝灰配色。Mermaid 11.17.2 在 `web/vendor` 本地提供，仅进入流程视图时加载，不使用远程 CDN。相关版本、许可证与更新命令见 `web/vendor/README.md`。

当前代码边界在图和讲解中保留：本地注册表尚未执行对象工具；schema 方法依赖未定义成员；计算器没有 UnaryOp 分支；SimpleAgent.remove_tool 的方法名与框架不一致。展示这些内容不代表对应功能已通过真实模型调用测试。
