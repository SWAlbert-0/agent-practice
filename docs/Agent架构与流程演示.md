# Agent 架构与流程演示

交互式前端位于项目根目录 `web`，用于探索当前组件、真实源码、关联关系和模拟数据流。核对日期：2026-10-17。

本文说明整体使用方式；独立的场景图浏览与维护见 [流程图视图说明](流程图视图说明.md)。

## 启动

在项目根目录使用 Python 3.11 或更高版本执行：

```powershell
python web/serve.py
```

打开 <http://127.0.0.1:5173>。无需 npm 安装，不会调用模型。端口被占用时使用 `python web/serve.py --port 5174`，按 `Ctrl+C` 停止服务。

启动时生成源码和图表索引。生成器只依赖 Python 标准库，读取白名单文件并解析 AST；不导入业务模块，不需要安装模型、消息或搜索相关业务依赖，也不读取配置文件或环境凭证。

## 当前能力

- 独立“流程图”视图展示 15 个核心场景，可与源码弹窗双向跳转；图定义复用 Markdown，不执行实际请求。

- 默认简化为 6 个组件，可切换到 31 个节点的完整图。点击简化组件可按需查看成员函数；两种视图分别保留布局与视图位置，简化连线由完整关系投影生成。
- 主页面仅保留架构图和必要控制，不设置侧边栏、标语、研发阶段或未来预览。
- 架构画布默认 100%，调整窗口大小不改变倍率；可手动缩放或适应画布，点击倍率回到 100%。
- 节点可拖动，连线实时跟随，连接关系保持不变；支持重置布局。拖动不会打开弹窗，点击才会。
- 左键移动节点，支持负坐标；按住右键或滚轮中键拖动整张架构画布，可向任意方向平移。普通滚轮纵向平移，Shift + 滚轮横向平移，Ctrl + 滚轮按指针位置缩放。独立流程图视图的普通滚轮则滚动页面。
- 点击节点打开接近全屏的模态窗口，左侧讲解、右侧真实源码同时展示；点击讲解步骤高亮源码，支持复制、换行和函数切换。
- 点击源码的调用或关联函数，按实际文件与限定符号进入实现；顶部调用链支持跳转到任意上层，返回时恢复步骤及滚动位置。
- 切换“信息流演示”展开播放、暂停、单步、重置、调速和模拟数据；演示不自动弹窗，主动查看节点会暂停。

当前入口为 `main.py → create_llm() → LLM.think() → LLM._request()`，没有创建 Agent 子类。SimpleAgent和ReActAgent均直接继承本地 `core.agent.Agent`；Message、Config、ToolRegistry和CalculatorTool也全部来自本地实现。

可选择 main.py、普通对话、工具循环和 ReAct 四种教学模拟；后三种不代表 main.py 已接入，也不会实际调用模型或工具。ReflectionAgent、PlanAndSolveAgent、搜索、工具链和并发执行器的现有实现也已纳入节点、源码与流程图；它们没有被虚构为 main 或 SimpleAgent 自动调用的下游。职责与边界见 [Agent 设计与执行流程](Agent设计与执行流程.md)。

## 展示范围与运行边界

- 浏览器读取 `web` 下的静态文件与生成索引，不读取真实 `.env`，不执行 Python 入口。
- 源码快照来自索引生成时的文件，不会因打开弹窗自动刷新。
- 源码中的调用链接按明确规则建立；未识别的动态调用不能据同名函数推断。
- 页面标注的实现状态和边界是教学说明，不是测试通过证明。
- 当前索引包含 24 个本地文件，包括 4 个 Agent、4 个 core 模块、7 个工具模块、main 及 8 个示例或离线测试文件。调用链接按导入别名、实际继承链、类型注解与静态构造关系解析；无法确定的动态工具对象不按同名函数猜测目标。

## 持续维护

更新展示内容时：

1. 使用项目环境运行 `python web/generate_sources.py` 更新源码与图表快照；或重启预览服务。
2. 在 `web/knowledge.js` 更新对应节点、讲解、关系及信息流演示；`web/app.js` 保持交互逻辑。关键函数说明与步骤以“文件::限定符号”为键。
3. 同步修改当前入口的信息流步骤及相关 Markdown 流程图，去除过期描述。
4. 验证页面中的说明与实际执行路径一致。

视图只维护当前代码状态，不预设开发路线；节点拖动只改变本次页面会话的布局，不改变 Python 代码或函数关联。

新增节点时同步维护 `web/map-views.js` 中的组件归属。主题集中于 `web/theme.css`，采用中性白灰和少量橙色强调，支持减少动态效果的系统偏好。

详细文件结构、操作和限制见 [web/README.md](../web/README.md)。
