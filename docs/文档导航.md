## 当前代码的几个区别

- `main.py` 是直接模型调用入口，不会创建 Agent。
- `core/llm.py` 提供 `create_llm()` 工厂，返回框架的 `HelloAgentsLLM`，不是另一个 LLM 子类。
- `agents/simple_agent.py` 和 `agents/react_agent.py` 继承框架同名类；本地 `core/agent.py` 不是它们的父类。
- ReflectionAgent 和 PlanAndSolveAgent 是本地实现，通过传入的客户端请求模型。
- 本地 `tools/registry.py` 与框架注册表不是同一个类；本地计算器示例使用前者，SimpleAgent 示例使用后者。
- 前端信息流是静态教学模拟，不是运行日志；源码索引只说明索引时的文件内容。

## 文档维护约定

1. 代码行为改变时，更新对应说明和流程图，明确哪些能力已实现、哪些仍有限制。
2. 模型配置的具体值集中在配置说明中；其他文档尽量解释机制，减少默认值重复与漂移。
3. `flows/核心代码流程.md` 的前七个 Mermaid 块和计算器文档的首个 Mermaid 块被 `web/flows.json` 按序号引用，不随意移动或插入图块。
4. 修改图定义后，需要刷新前端索引才会在页面生效。只整理文档时，不自动修改 `web` 下的生成文件。
5. 不在文档记录真实密钥；示例引用环境变量名或本地占位值。

文件 `Agent研发地图说明.md` 保留原路径，以兼容已有链接，其页面标题统一为“Agent 架构与流程演示”。
