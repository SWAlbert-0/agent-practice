## 当前代码的几个区别

- `main.py` 是直接模型调用入口，不会创建 Agent。
- `core/llm.py` 提供本地 `LLM` 类和 `create_llm()` 工厂。
- SimpleAgent和ReActAgent直接继承本地 `core.agent.Agent`，消息与配置也使用本地实现。
- ReflectionAgent 和 PlanAndSolveAgent 是本地实现，通过传入的客户端请求模型。
- 各业务模块统一使用本地注册表，支持对象和函数两种工具；对象计算器注册名为 `calculator`，函数计算器为 `calculate`。
- 搜索实现统一为 SearchTool 对象，注册名称为 search，支持 Tavily / SerpApi 与固定顺序回退。
- 工具链和异步执行器已有实现，但未接入 Agent；研究工具链示例仍有名称、输入格式和注册环节的缺口。
- 前端信息流是静态教学模拟，不是运行日志；源码索引只说明索引时的文件内容。

## 文档维护约定

1. 代码行为改变时，更新对应说明和流程图，明确哪些能力已实现、哪些仍有限制。
2. 模型配置的具体值集中在配置说明中；其他文档尽量解释机制，减少默认值重复与漂移。
3. `flows/核心代码流程.md` 的前七个 Mermaid 块和工具调用文档的第二个 Mermaid 块被 `web/flows.json` 按序号引用，不随意移动或插入图块。
4. 修改图定义后，需要刷新前端索引才会在页面生效。只整理文档时，不自动修改 `web` 下的生成文件。
5. 不在文档记录真实密钥；示例引用环境变量名或本地占位值。
