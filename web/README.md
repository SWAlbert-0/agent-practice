# Agent Explorer

本地交互式 Agent 研发地图。采用原生 HTML/CSS/JavaScript，无需安装 npm 依赖，不依赖在线 CDN。不修改 Python 业务代码，不连接模型服务。

## 启动

在项目根目录、激活 `hello-agents` 环境后运行：

```powershell
python web/serve.py
```

打开 **http://127.0.0.1:5173**。使用 `Ctrl+C` 停止服务。端口被占用时：

```powershell
python web/serve.py --port 5174
```

启动时自动生成 `sources.json` 和 `diagrams.json`。请用安装了 `hello_agents` 的 Python 环境运行，以便同时展示第三方客户端源码；缺少该包时仍可查看项目其他文件。

## 交互

- 流程图：顶部独立视图提供 8 个核心场景，时序图展示跨组件调用，流程图展示判断与循环。可从图打开源码弹窗，也可从源码弹窗进入相关流程；支持平移、缩放、100% 和适应画布。详细说明见 [流程图视图说明](../docs/流程图视图说明.md)。

- 显示层级：默认“简化显示”，将 23 个节点收拢为 6 个组件（入口、连接、Agent、模型客户端、工具、基础组件）。点击组件，在弹窗内按需进入具体节点；“完全展开”显示所有函数与组件节点。
- 简化图的关系由完整图按组件归属汇总，隐藏组内连线，合并重复的跨组关联，不增加推测的调用。两种视图各自保留拖动布局、缩放和平移状态。
- 点击节点：打开接近全屏的详情弹窗，左侧功能讲解、右侧真实源码同时展示。小屏幕上下排列，两个区域独立滚动。
- 步骤对照：点击左侧执行步骤，定位并高亮右侧对应源码行；支持复制源码和自动换行。
- 调用链导航：点击源码下划线调用或左侧依赖，按“文件 + 限定符号”进入实际实现；顶部面包屑和返回按钮支持逐层回退，并保留步骤选择及滚动位置。
- 信息流：点击“信息流演示”才展开控制和数据；播放、暂停、单步、重置和调速。播放不会自动弹出详情，主动查看节点时会暂停播放。
- 视图：默认 100%，调整窗口大小不会改变倍率。手动点击缩放按钮或“适应画布”，点击倍率恢复 100%。缩放以视口中心为锚点，Ctrl + 滚轮以指针为锚点。
- 平移：按住鼠标右键或滚轮中键拖动整张地图，支持任意方向，不受边界限制。在节点上按右键/中键也会平移地图，不会移动单个节点。普通滚轮纵向平移，Shift + 滚轮横向平移。
- 节点：左键拖动调整位置，支持负坐标，不受原点限制。连线实时跟随；关系不随拖动、缩放或播放改变。拖动不会误打开详情。键盘可用 Alt + 方向键移动，按住 Shift 加大步长。
- 布局：点击“重置布局”恢复节点初始位置、视图居中和 100% 倍率；拖动布局和相机位置在本次页面会话中保留，刷新恢复默认。
- 内容：无侧边栏、标语、研发阶段或未来预览，只展示当前代码中已有的组件和关系。

信息流不是实际运行 trace。提供当前 main.py、SimpleAgent 普通对话、工具循环三种教学模拟；后两者是方法级演示，当前 main.py 尚未接入 Agent，也没有实际执行工具。所有模拟数据均在前端生成。

## 当前代码关系与注意事项

项目 `agents/simple_agent.py` 的 SimpleAgent 继承安装包的 SimpleAgent，后者继承框架 Agent；并非项目 `core/agent.py`。Message、Config、ToolRegistry 同样从安装包导入。同名本地类与框架类使用完整路径区分。

同步普通对话和工具循环已写入项目源码。关键入口包含 run、invoke、增强提示词、工具标记解析、参数解析、工具执行与注册表方法。invoke 的下游 chat.completions.create 属于 OpenAI SDK，本版展示调用边界，不伪造未索引的实现。

stream_run 已使用 get_history()，其他工具分支已调用 tool.run()；地图已移除过期的错误提示。仍保留当前实现的边界：remove_tool 与框架 unregister 方法名不匹配；本地注册表只执行函数工具，schema 方法依赖未定义成员；计算器尚无 UnaryOp 分支。此次仅更新展示与索引，没有改动 Python 业务代码。

## 随开发更新

1. 修改 Python 文件后执行 `python web/generate_sources.py`，刷新浏览器，即可更新真实源码和 AST 定位的函数行号。重启预览服务也会更新。
2. 在 `app.js` 的 `nodes` 和 `knowledge.js` 的 `extraNodes` 中维护地图节点、状态和位置。
3. 在 `knowledge.js` 的 `notes` 中按“文件::类.方法”维护讲解、输入输出、问题提示及步骤定位；步骤使用函数体内的源码文本定位，不硬编码行号。
4. 在 `relations` / `extraRelations` 中维护真实关系，在 `currentFlow` / `flowExamples` 中维护模拟。前端 AST 调用链接由 Python 索引器的明确规则生成，未识别的动态调用不按同名猜测。
5. 新增节点后，在 `map-views.js` 中指定它所属的组件；每个节点只属于一组，简化图自动从完整关系生成。无需手工维护第二套调用关系。

按用户要求更新当前地图；不预设研发阶段，也不自动推断未来能力。源码索引、讲解和关系需要一起核对，不能只刷新源码就假定整张图已经同步。

## 文件

| 文件 | 用途 |
|---|---|
| `index.html` | 页面结构与交互控件 |
| `styles.css` | 响应式布局与画布风格 |
| `disclosure.css` | 按需展开的简洁布局和详情弹窗 |
| `app.js` | 组件知识、关系图、关联跳转和播放状态 |
| `knowledge.js` | 新增 Agent 图谱、逐函数讲解、步骤锚点和方法模拟 |
| `reader.js` | 左右分栏源码阅读器、精确调用导航、面包屑和阅读状态 |
| `reader.css` | 源码阅读器布局和代码行高亮 |
| `map-views.js` | 完整节点的组件归属、简化图与关系投影 |
| `theme.css` | 中性白灰与少量橙色强调、圆角卡片、轻量切换动效 |
| `diagrams.js` / `diagrams.css` | 独立流程视图、图与源码互跳、平移和缩放 |
| `flows.json` | 文档图目录与精确源码关联，人工维护 |
| `diagrams.json` | 从 Markdown 提取的 Mermaid 定义，自动生成 |
| `vendor/mermaid.js` | 本地 Mermaid 11.17.2，进入流程视图才加载 |
| `generate_sources.py` | 仅对白名单 Python 文件生成 AST 源码索引 |
| `sources.json` | 自动生成的源码快照，不应手工修改 |
| `serve.py` | 只绑定本机、只提供 web 目录的静态预览 |

白名单包含 main.py、core 下四个基础模块、项目 SimpleAgent、本地工具三文件、两个测试入口，以及可用时的八个框架模块（包括工具基类及框架计算器），目前共 19 个文件。不读取 `.env` 或 `models.json`，不执行项目入口或请求模型。新增索引文件前需确认其不包含硬编码密钥。

这版采用原生 SVG、DOM 和 Pointer Events 实现交互。节点和连线共用可为负数的世界坐标，独立相机通过 translate/scale 控制视图，避免使用有限滚动区域限制拖动。SVG 允许内容越过自身原点，只有最外层视口裁切显示。连接端点固定为节点 ID，不支持在界面中改连线关系。

## 视觉设计

参考 [MangoDisk](https://mangodisk.app/zh) 的圆角、柔和阴影和轻量动效，独立实现应用界面。根据阅读反馈，主界面及弹窗采用中性白灰、蓝灰文字，橙色仅作选中和演示强调，源码区采用中性深色。使用浏览器原生 CSS 完成显示层级的滑动指示、地图淡入、弹窗轻量进场、按钮和卡片悬停反馈，不引入站点素材或远程运行依赖。遵循 prefers-reduced-motion，用户减少动态效果时关闭动画。节点拖动和相机平移不使用延迟过渡，确保连线即时跟随。
