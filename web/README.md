# Agent 架构与流程演示

本地交互式 Agent 架构与流程演示。采用原生 HTML/CSS/JavaScript，无需安装 npm 依赖，不依赖在线 CDN。不修改 Python 业务代码，不连接模型服务。

## 启动

使用 Python 3.11，在项目根目录运行：

```powershell
python web/serve.py
```

打开 **http://127.0.0.1:5173**。使用 `Ctrl+C` 停止服务。端口被占用时：

```powershell
python web/serve.py --port 5174
```

启动时自动生成 `sources.json`、`examples.json` 和 `diagrams.json`。索引生成器只使用Python标准库，解析本地源码，不导入业务模块或第三方框架。

## 交互

- 流程图：顶部独立视图提供 15 个核心场景，时序图展示跨组件调用，流程图展示判断与循环。可从图打开源码弹窗，也可从源码弹窗进入相关流程；支持平移、缩放、100% 和适应画布。详细说明见 [流程图视图说明](../docs/流程图视图说明.md)。
- 图表类型筛选：按目录中的 `kind` 自动生成选项，当前包含全部类型、流程图（10 个）和时序图（5 个）。从源码跨类型打开图表时同步筛选条件；新增类型无需修改筛选逻辑。

- 显示层级：结构关系默认“简化显示”，将 27 个业务节点收拢为 6 个组件（入口、连接、Agent、模型客户端、工具、基础组件），不包含 examples / tests 节点。点击组件，在弹窗内按需进入具体节点；“完全展开”显示所有函数与组件节点。
- 简化图的关系由完整图按组件归属汇总，隐藏组内连线，合并重复的跨组关联，不增加推测的调用。两种视图各自保留拖动布局、缩放和平移状态。
- 点击节点：打开接近全屏的详情弹窗，左侧功能讲解、右侧真实源码同时展示。小屏幕上下排列，两个区域独立滚动。
- 步骤对照：点击左侧执行步骤，定位并高亮右侧对应源码行；支持复制源码和自动换行。
- 调用链导航：点击源码下划线调用或左侧依赖，按“文件 + 限定符号”进入实际实现；顶部面包屑和返回按钮支持逐层回退，并保留步骤选择及滚动位置。
- 案例与测试：与结构关系、信息流演示、流程图同级，集中展示原有的 2 个示例节点和 1 个测试节点。点击卡片查看真实源码，也可点击关联实现进入业务方法；结构图的组件弹窗中不再混入这些节点。信息流仍可使用示例入口解释执行步骤。
- 信息流：从 `examples/` 源码自动发现示例入口，目前包含 8 个入口。切换示例时，仅显示该入口能够静态关联到的节点和连线；简化与完全展开均遵循此范围。支持播放、暂停、上一步、单步、直接跳转、重置和调速；显示调用表达式与返回约定，点击“查看当前调用处”定位真实源码行。播放不自动打开弹窗。
- 视图：默认 100%，调整窗口大小不会改变倍率。手动点击缩放按钮或“适应画布”，点击倍率恢复 100%。缩放以视口中心为锚点，Ctrl + 滚轮以指针为锚点。
- 平移：按住鼠标右键或滚轮中键拖动整张地图，支持任意方向，不受边界限制。在节点上按右键/中键也会平移地图，不会移动单个节点。普通滚轮纵向平移，Shift + 滚轮横向平移。
- 节点：左键拖动调整位置，支持负坐标，不受原点限制。连线实时跟随；关系不随拖动、缩放或播放改变。拖动不会误打开详情。键盘可用 Alt + 方向键移动，按住 Shift 加大步长。
- 布局：点击“重置布局”恢复节点初始位置、视图居中和 100% 倍率；拖动布局和相机位置在本次页面会话中保留，刷新恢复默认。
- 内容：无侧边栏、标语、研发阶段或未来预览，只展示当前代码中已有的组件和关系。

信息流是从源码生成的调用展开，不是真实运行 trace。不预设模型回答或工具结果，也不执行 Python。分支和循环展示静态可见的关系，每个方法只展开一次；无法静态识别的动态调用不按同名猜测。实际执行顺序、分支选择、循环次数和返回值以运行示例为准。

## 当前代码关系与注意事项

SimpleAgent 和 ReActAgent 均直接继承本地 `core/agent.py` 中的 Agent。LLM、Message、Config、ToolRegistry、CalculatorTool 也由本地模块实现。

同步普通对话和工具循环已写入项目源码。关键入口包含 run、invoke、增强提示词、工具标记解析、参数解析、工具执行与注册表方法。invoke 的下游 chat.completions.create 属于 OpenAI SDK，本版展示调用边界，不伪造未索引的实现。

注册表已支持对象和函数工具，remove_tool 已对接本地 unregister_tool。仍保留当前边界：schema 方法依赖未定义成员；计算器尚无 UnaryOp 分支；函数注册不代表 SimpleAgent 的对象工具分支能够直接调用。

## 随开发更新

1. 修改 Python 文件后执行 `python web/generate_sources.py`，刷新浏览器，即可更新真实源码和 AST 定位的函数行号。重启预览服务也会更新。
2. 在 `app.js` 的 `nodes` 和 `knowledge.js` 的 `extraNodes` 中维护地图节点、状态和位置。
3. 在 `knowledge.js` 的 `notes` 中按“文件::类.方法”维护讲解、输入输出、问题提示及步骤定位；步骤使用函数体内的源码文本定位，不硬编码行号。
4. 在 `relations` / `extraRelations` 中维护结构关系。信息流无需手工添加固定案例：在 `examples/` 新增 Python 示例并重新生成索引即可。优先发现 `if __name__ == "__main__"` 调用的本文件函数；没有此入口时，收集公开函数或脚本入口。已有示例的中文名称与学习顺序在 `generate_sources.py` 的 `EXAMPLE_LABELS` 中按顺序维护；新入口自动追加，默认标题取函数文档字符串。调用步骤与节点来自 AST 索引。
5. 新增节点后，在 `map-views.js` 中指定它所属的组件；每个节点只属于一组，简化图自动从完整关系生成。无需手工维护第二套调用关系。

按用户要求更新当前地图；不预设研发阶段，也不自动推断未来能力。源码索引、讲解和关系需要一起核对，不能只刷新源码就假定整张图已经同步。

## 文件

| 文件 | 用途 |
|---|---|
| `index.html` | 页面结构与交互控件 |
| `styles.css` | 响应式布局与画布风格 |
| `disclosure.css` | 按需展开的简洁布局和详情弹窗 |
| `app.js` | 组件知识、关系图、关联跳转和播放状态 |
| `knowledge.js` | 新增 Agent 图谱、逐函数讲解、步骤锚点和方法模拟 |
| `cases.js` | 从示例入口生成相关节点、关系及源码调用步骤 |
| `examples.json` | 自动发现的示例入口目录，不应手工修改 |
| `validate.js` / `check.mjs` | 共用引用检查与命令行一致性检查 |
| `reader.js` | 左右分栏源码阅读器、精确调用导航、面包屑和阅读状态 |
| `reader.css` | 源码阅读器布局和代码行高亮 |
| `map-views.js` | 完整节点的组件归属、简化图与关系投影 |
| `theme.css` | 中性白灰与少量橙色强调、圆角卡片、轻量切换动效 |
| `diagrams.js` / `diagrams.css` | 独立流程视图、图与源码互跳、平移和缩放 |
| `flows.json` | 文档图目录与精确源码关联，人工维护 |
| `diagrams.json` | 从 Markdown 提取的 Mermaid 定义，自动生成 |
| `vendor/mermaid.js` | 本地 Mermaid 11.17.2，进入流程视图才加载 |
| `generate_sources.py` | 为业务白名单与 examples 下的 Python 示例生成 AST 源码索引 |
| `sources.json` | 自动生成的源码快照，不应手工修改 |
| `serve.py` | 只绑定本机、只提供 web 目录的静态预览 |

业务白名单由 `generate_sources.py` 的 SOURCE_FILES 维护，包含项目入口、基础组件、Agent、工具和选定测试文件；另外自动收集 `examples/` 下文件名不以 `_` 开头的 Python 文件。不读取 `.env` 或 `models.json`，不执行项目入口或请求模型。新增索引文件前需确认其不包含硬编码密钥。

这版采用原生 SVG、DOM 和 Pointer Events 实现交互。节点和连线共用可为负数的世界坐标，独立相机通过 translate/scale 控制视图，避免使用有限滚动区域限制拖动。SVG 允许内容越过自身原点，只有最外层视口裁切显示。连接端点固定为节点 ID，不支持在界面中改连线关系。

## 视觉设计

参考 [MangoDisk](https://mangodisk.app/zh) 的圆角、柔和阴影和轻量动效，独立实现应用界面。根据阅读反馈，主界面及弹窗采用中性白灰、蓝灰文字，橙色仅作选中和演示强调，源码区采用中性深色。使用浏览器原生 CSS 完成显示层级的滑动指示、地图淡入、弹窗轻量进场、按钮和卡片悬停反馈，不引入站点素材或远程运行依赖。遵循 prefers-reduced-motion，用户减少动态效果时关闭动画。节点拖动和相机平移不使用延迟过渡，确保连线即时跟随。

## 一致性检查与验证

更新代码或演示后，在项目根目录执行（命令行检查需要 Node.js）：

```powershell
python web/generate_sources.py
node web/check.mjs
node --test web/tests/consistency.test.mjs
node --test web/tests/diagram-types.test.mjs
node --test web/tests/diagram-layout.test.mjs
node --test web/tests/map-views.test.mjs
python web/tests/test_example_catalog.py
```

检查覆盖节点文件和方法、关系端点、讲解步骤的源码定位、案例步骤、源码跳转、组件归属、文档流程图及生成快照。任何失效引用或过期快照会输出具体位置并返回失败状态。此检查验证引用与定位，不自动判断讲解语义；改动分支或返回值时仍需核对说明和案例。

页面启动时也检查引用，顶部显示核对结果；浏览器只核对已加载的静态索引，磁盘源码是否比索引更新由命令行检查。

弹窗统一采用“负责什么、接收与返回、调用谁”的说明结构，执行步骤与源码对照按需查看。信息流仅展示源码表达式和返回约定，不编造实际返回值；页面不读取密钥、不调用模型、不运行 Python 工具。

可选浏览器回归脚本为 `web/tests/browser_smoke.py`，需要额外安装 Playwright 及 Chromium（不属于项目运行依赖），并先启动预览服务：

```powershell
python -m pip install playwright
python -m playwright install chromium
# 在另一个终端启动 python web/serve.py --port 5174 后执行：
python web/tests/browser_smoke.py
python web/tests/diagrams_browser.py
python web/tests/fixed_diagrams_browser.py
python web/tests/practice_browser.py
```

脚本检查当前自动发现的示例入口及其每一步、源码高亮、调用跳转、暂停与重置，以及桌面和手机布局。`WEB_TEST_URL` 可指定服务地址，`WEB_TEST_OUTPUT` 可指定截图目录；默认使用系统临时目录保存截图。

`diagrams_browser.py` 另外检查图类型筛选、15 个图的真实 Mermaid 渲染、跨类型源码跳转、缩放状态和小屏布局。

## 图表阅读样式

沿用页面的简洁布局，图中使用浅蓝处理节点、浅琥珀菱形判断节点、深色标签和低干扰网格。判断同时由形状和“是 / 否”等源码标签表达，不只依赖颜色。时序图统一参与者宽度，增大消息间距，使用虚线生命线，保留定义中的消息编号和调用 / 返回箭头。主题只调整展示，不修改流程关系或 Python 业务代码。

默认保持 100% 倍率；长图可拖动查看或手动适应画布，适应后可恢复 100% 阅读文字。每张图保留本次会话中的平移与缩放状态。

点击“固定画布”可进入窗口内的固定阅读模式，操作栏和相关源码入口保持可见。图表按可用空间自动适配，最小缩放为 90%；当完整图放不下时保留可读尺寸，并提供横向和纵向滚动范围。滚轮、触控板、触屏滑动及右键 / 中键拖动均可查看超出部分，聚焦画布后也可用键盘滚动。宽图在小屏上首先定位入口，避免初始视野落在空白区域。

调整窗口大小或切换图表会重新适配；手动放大后滚动范围随之扩大。点击“退出固定”或按 Esc 返回自由画布，恢复之前的缩放和平移；源码弹窗中的 Esc 仅关闭弹窗，不退出固定模式。固定模式的布局、可读下限和完整滚动范围由 `diagram-layout.test.mjs` 与 `fixed_diagrams_browser.py` 验证。

视觉原则参考 [IBM Carbon 数据可视化](https://www.carbondesignsystem.com/building-blocks/data-visualization/overview) 对清晰、准确和可访问性的强调；具体排版通过 [Mermaid 主题配置](https://mermaid.js.org/config/theming.html) 与图类型布局参数实现，并非声称符合某个公司的完整制图规范。

新增类型时，在 `flows.json` 填写相应 `kind` 并指向文档中的 Mermaid 图块，再重新生成索引即可。筛选器自动收集新类型；渲染能力取决于项目内置 Mermaid 的支持范围。无需提前添加不存在的示例。
