使用指南

  1. 点击节点打开详情弹窗，左侧功能讲解与右侧真实源码并排展示；点击左侧步骤定位并高亮代码。
  2. 左键拖动节点，可越过原点向任意方向移动，连线自动跟随，连接关系不变；“重置布局”恢复初始位置。也可聚焦节点，按 Alt + 方向键移动。
  3. 地图默认 100%，可手动缩放、适应画布，点击倍率恢复 100%。按住右键或滚轮中键可向任意方向拖动整张地图；滚动滚轮也可平移，Shift + 滚轮横移。
  4. 点击源码下划线调用进入真实实现；顶部调用链可跳转到任意上层，左箭头逐层返回。支持函数选择、复制和自动换行。
  5. 点击“信息流演示”选择 main.py、Agent 普通对话或工具循环；Agent 路径仅为方法级模拟，未接入当前 main.py。
  6. 按 Esc、点击关闭按钮或窗口外部可关闭弹窗。
